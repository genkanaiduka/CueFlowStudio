プライバシーポリシー (Privacy Policy)

対象アプリケーション: CueFlow Studio for macOS / 最終改定日: 2026年10月16日

要約 (Summary): CueFlow Studio は、舞台・劇場・イベント・放送現場におけるミッションクリティカルな送出用途向けに設計されており、ユーザーの個人情報、閲覧履歴、メディアファイル、位置情報等の収集・外部送信は一切行いません。すべての処理は macOS ローカル環境内で完結します。

1. 収集する情報とその利用

CueFlow Studio は、ユーザーの個人を特定できる情報（氏名、メールアドレス、電話番号、IPアドレスなど）を収集しません。

  • メディアファイルおよびプロジェクトデータ: 本アプリで読み込まれた動画、静止画、音声ファイル、およびキュー設定情報（.cueflow プロジェクトファイル）は、すべてお客様の Mac のローカルストレージ上でのみ処理されます。外部サーバーやクラウドへの自動アップロードは一切行われません。
  • ローカルストレージの利用: アプリケーションの設定（外部ディスプレイ選択、解像度・フレームレート・スキャンモードの変換設定、音量等）は、次回起動時の復元のために macOS のローカルストレージ（Sandbox 隔離領域内）にのみ保存されます。

2. ネットワーク通信について

CueFlow Studio は外部インターネットとの不要な通信を行いません。アプリ内部に組み込まれた HTTP ストリーミングエンジン（127.0.0.1:8080）は、macOS 内のローカルプロセス間でのみ動作する純粋なループバック通信であり、外部ネットワークへ開かれたり外部からのアクセスを受け付けたりすることはありません。

3. サードパーティ製 SDK・トラッキングツールについて

本アプリケーションには、広告配信 SDK、行動トラッキング SDK（Google Analytics、Firebase 等）、クラッシュ解析用のサードパーティ製ライブラリ等は一切含まれていません。完全なオフライン環境（インターネット未接続の現場環境）でも全機能が完全に動作します。

4. ハードウェアへのアクセスについて

  • 外部ディスプレイおよびビデオ I/O: セカンダリプロジェクターや Blackmagic Design 社製 DeckLink / UltraStudio ハードウェアへの映像送出のために macOS の CoreGraphics および専用ドライバインターフェースを使用します。これらはすべて映像出力のみに利用されます。
  • オーディオデバイス: CoreAudio を介して接続されたオーディオインターフェースやヘッドフォンへの音声出力のみを行います。マイク入力や環境音の録音・収集は行いません。
